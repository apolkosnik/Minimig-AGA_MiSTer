# MC68020 vs MC68030 Feature Comparison

## Document Purpose

This document provides a detailed comparison between the MC68020 and MC68030 processors, highlighting the differences that need to be implemented to upgrade from TG68K's current 68020 support to full MC68030 functionality.

## Executive Summary

The MC68030 is an evolutionary enhancement of the MC68020, adding:
- ✅ **On-chip MMU** (Memory Management Unit) - *Major addition*
- ✅ **On-chip caches** (256-byte I-cache + 256-byte D-cache) - *Major addition*
- ✅ **New MMU instructions** (PMOVE, PFLUSH, PTEST)
- ✅ **Enhanced bus interface** (burst mode, dynamic bus sizing)
- ✅ **Enhanced cache control** (extended CACR, new CAAR)

**Backward Compatibility**: MC68030 is fully backward compatible with MC68020 software.

## Detailed Feature Comparison

### 1. Memory Management Unit (MMU)

| Feature | MC68020 | MC68030 |
|---------|---------|---------|
| **On-Chip MMU** | ❌ No (requires external 68851) | ✅ Yes (integrated) |
| **Address Translation** | External only | On-chip |
| **ATC (Translation Cache)** | N/A | 22 entries, fully associative |
| **Table Levels** | N/A | Up to 5 levels |
| **Page Sizes** | N/A | 256B to 32KB |
| **Transparent Translation** | N/A | 2 registers (TT0, TT1) |
| **MMU Registers** | None | TC, TT0, TT1, CRP, SRP, MMUSR |

**Implementation Impact**: HIGH
- Need to implement full MMU module
- Add ATC (Address Translation Cache)
- Implement table walk logic
- Add MMU control registers

### 2. On-Chip Caches

| Feature | MC68020 | MC68030 |
|---------|---------|---------|
| **Instruction Cache** | ✅ 256 bytes (optional) | ✅ 256 bytes (standard) |
| **Data Cache** | ❌ No | ✅ 256 bytes |
| **Cache Organization** | Direct-mapped | Direct-mapped |
| **Line Size** | 16 bytes (4 longwords) | 16 bytes (4 longwords) |
| **Write Policy** | N/A | Write-through |
| **Cache Control** | CACR (basic) | CACR (enhanced) |
| **Cache Operations** | Limited | CINV instruction |

**Implementation Impact**: MEDIUM-HIGH
- Add data cache (instruction cache may already exist in some form)
- Enhance CACR functionality
- Implement CAAR (Cache Address Register)
- Add cache invalidation logic

### 3. Control Registers

| Register | MC68020 | MC68030 | Bits | Purpose |
|----------|---------|---------|------|---------|
| **VBR** | ✅ Yes | ✅ Yes | 32 | Vector Base Register |
| **CACR** | ✅ Yes (basic) | ✅ Yes (enhanced) | 32 | Cache Control Register |
| **CAAR** | ❌ No | ✅ Yes | 32 | Cache Address Register |
| **TC** | ❌ No | ✅ Yes | 32 | Translation Control |
| **TT0** | ❌ No | ✅ Yes | 32 | Transparent Translation 0 |
| **TT1** | ❌ No | ✅ Yes | 32 | Transparent Translation 1 |
| **MMUSR** | ❌ No | ✅ Yes | 16 | MMU Status Register |
| **CRP** | ❌ No | ✅ Yes | 64 | CPU Root Pointer |
| **SRP** | ❌ No | ✅ Yes | 64 | Supervisor Root Pointer |
| **SFC** | ✅ Yes | ✅ Yes | 3 | Source Function Code |
| **DFC** | ✅ Yes | ✅ Yes | 3 | Destination Function Code |

**Implementation Impact**: MEDIUM
- Add 7 new registers (TC, TT0, TT1, CAAR, MMUSR, CRP, SRP)
- Enhance CACR bit definitions
- Implement MOVEC support for new registers

### 4. CACR (Cache Control Register) Comparison

#### MC68020 CACR
```
Bit 0: Enable Cache (C)
Bit 1: Freeze Cache (F)
Bit 2: Clear Entry (CE)
Bit 3: Clear Cache (CL)
Bits 4-31: Reserved
```

#### MC68030 CACR
```
Bit 0: Enable Instruction Cache (EI)
Bit 1: Freeze Instruction Cache (FI)
Bit 2: Clear Instruction Cache Entry (CEI)
Bit 3: Clear Instruction Cache (CI)
Bit 4: Instruction Burst Enable (IBE)
Bit 5-7: Reserved
Bit 8: Enable Data Cache (DE)
Bit 9: Freeze Data Cache (FD)
Bit 10: Clear Data Cache Entry (CDE)
Bit 11: Clear Data Cache (CD)
Bit 12: Data Burst Enable (DBE)
Bit 13: Write Allocate (WA)
Bits 14-31: Reserved
```

**Implementation Impact**: LOW
- Extend CACR from 4 bits to 14 functional bits
- Implement separate I-cache and D-cache control
- Add burst enable flags

### 5. Instruction Set Differences

| Instruction | MC68020 | MC68030 | Purpose |
|-------------|---------|---------|---------|
| **PMOVE** | ❌ No (68851 only) | ✅ Yes | Move to/from MMU registers |
| **PFLUSH** | ❌ No (68851 only) | ✅ Yes | Flush ATC entries |
| **PTEST** | ❌ No (68851 only) | ✅ Yes | Test address translation |
| **PLOAD** | ❌ No (68851 only) | ✅ Optional | Load ATC entry |
| **CINV** | ❌ No | ✅ Yes | Cache invalidate |
| **CPUSH** | ❌ No | ✅ Optional | Cache push (not used in 030) |
| All others | ✅ Same | ✅ Same | Fully compatible |

**Implementation Impact**: MEDIUM
- Add decode for PMOVE (multiple variants)
- Add decode for PFLUSH (multiple variants)
- Add decode for PTEST
- Add decode for CINV

**Note**: MC68030 instructions that were exclusive to the external 68851 MMU on 68020 systems are now integrated.

### 6. Bus Interface

| Feature | MC68020 | MC68030 | Notes |
|---------|---------|---------|-------|
| **Address Bus** | 32-bit | 32-bit | Same |
| **Data Bus** | 32-bit | 32-bit | Same |
| **Burst Mode** | ❌ No | ✅ Yes | 4-beat burst for cache fills |
| **Dynamic Bus Sizing** | ✅ Basic | ✅ Enhanced | Auto 8/16/32-bit port |
| **Bus Signals** | Standard | Enhanced | Added CBREQ, CBACK |
| **Function Codes** | ✅ FC0-FC2 | ✅ FC0-FC2 | Same |
| **Async Termination** | DSACK | DSACK | Same |

**Implementation Impact**: MEDIUM (for burst mode)
- LOW if burst mode not implemented
- MEDIUM if burst mode implemented for cache line fills

### 7. Exception Processing

| Feature | MC68020 | MC68030 | Notes |
|---------|---------|---------|-------|
| **Stack Frames** | Formats 0-9 | Formats 0-B | Added format A, B |
| **Bus Error** | Format 9 (long) | Format B (enhanced) | More detailed |
| **MMU Exceptions** | N/A | New | Access errors from MMU |
| **Exception Vectors** | 0-255 | 0-255 | Same range |

**Implementation Impact**: MEDIUM
- Add stack frame formats A and B
- Add MMU-related exception vectors
- Enhance bus error handling

## TG68K Current Status vs MC68030 Requirements

### Already Implemented in TG68K ✅

1. ✅ 32-bit data/address buses
2. ✅ All basic 68000/68010/68020 instructions
3. ✅ Extended addressing modes (68020)
4. ✅ 32-bit multiply/divide (68020)
5. ✅ Bitfield instructions (68020)
6. ✅ CAS/CAS2, CHK2/CMP2 (68020)
7. ✅ PACK/UNPK, EXTB (68020)
8. ✅ VBR (Vector Base Register)
9. ✅ Basic CACR (Cache Control Register)
10. ✅ MOVEC instruction (partial)

### Needs Implementation for MC68030 ⏳

#### High Priority (Core MC68030 Features)
1. ⏳ **MMU Registers**: TC, TT0, TT1, CRP, SRP, MMUSR
2. ⏳ **PMOVE Instruction**: Access MMU registers
3. ⏳ **PFLUSH Instruction**: Flush ATC
4. ⏳ **PTEST Instruction**: Test translation
5. ⏳ **ATC Module**: 22-entry translation cache
6. ⏳ **Transparent Translation**: TT0/TT1 logic
7. ⏳ **Data Cache**: 256-byte D-cache
8. ⏳ **Enhanced CACR**: Separate I/D cache control
9. ⏳ **CAAR Register**: Cache address register
10. ⏳ **CINV Instruction**: Cache invalidate

#### Medium Priority (Enhanced Features)
11. ⏳ **Table Walk Logic**: MMU page table traversal
12. ⏳ **MMU Exceptions**: Access errors, invalid descriptors
13. ⏳ **Stack Frames A/B**: New exception frames
14. ⏳ **MOVEC Enhancement**: Support new registers

#### Low Priority (Optional/Performance)
15. ⏳ **Burst Mode**: 4-beat burst transfers
16. ⏳ **Enhanced Bus Sizing**: Better dynamic sizing
17. ⏳ **PLOAD Instruction**: Optional ATC preload

- ✅ Add CAAR register

### Medium (3-5 days each)
- ⚠️ PFLUSH instruction (ATC flush operations)

## Minimig-Specific Considerations

### What Amiga OS Uses

**Typically Used**:
- ✅ Basic instruction set (100% usage)
- ✅ Addressing modes (100% usage)
- ✅ Interrupts and exceptions (100% usage)
- ⚠️ CACR (some OS versions check/set)
- ⚠️ VBR (OS uses for relocatable vectors)

**Sometimes Used**:
- ⚠️ MMU (AmigaOS 3.x with 68030 libraries)
- ⚠️ 32-bit multiply/divide (some software)
- ⚠️ Bitfield instructions (some software)

**Rarely Used**:
- ❓ Full MMU features (mostly for memory protection)
- ❓ PMOVE, PFLUSH, PTEST (OS doesn't heavily use)

### Minimal MC68030 for Amiga

For Amiga compatibility, a simplified MC68030 could:

1. ✅ **Implement all registers** (read/writable)
2. ✅ **Implement all instructions** (decode correctly)
3. ✅ **Implement basic caches** (even if simplified)
4. ⚠️ **Simplified MMU**: Transparent translation only
5. ⚠️ **Optional full MMU**: Add later if needed

This approach allows software to:
- Detect MC68030 processor
- Access all registers without exceptions
- Execute all instructions
- Benefit from caching
- Function without full MMU (most software doesn't need it)

## Phased Implementation Strategy

### Phase 1: Registers and Instructions (Weeks 1-2)
Implement registers and instruction decode without full functionality:
- Add all MMU registers (read/write only)
- Add CAAR register
- Implement PMOVE, PFLUSH, PTEST (basic)
- Implement CINV (basic)
- Software can now detect MC68030

### Phase 2: Caches (Weeks 3-4)
Implement cache structures:
- Data cache (256 bytes)
- Enhanced I-cache control
- Cache invalidation
- Basic performance improvement visible

### Phase 3: Transparent Translation (Week 5)
Implement TT0/TT1:
- Address range matching
- Function code matching
- Transparent translation bypass
- Basic MMU functionality works

### Phase 4: Full MMU (Weeks 6-8)
Implement complete MMU:
- ATC structure
- Table walk logic
- MMU exception handling
- Full memory management available

### Phase 5: Bus Enhancements (Week 9+)
Optional performance enhancements:
- Burst mode
- Enhanced bus sizing
- Performance optimization
